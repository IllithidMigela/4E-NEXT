# 术语（reference）私设编辑器设计

> 优先级：**P3**（轻量文本）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/reference.json`（38 条，多数 sourceText 为空、词条定义以 name/tags 承载）

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/出处）+ 正文（词条定义）。引用它的词条/威能正文经 `[[链接]]` 悬浮预览。

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| sourceText 正文 | longtext | ✅（主体） |

## 三、设计要点

1. **保持正文为主**：术语定义是自由文本，无需结构化为标签块。
2. 可选增强：**关联词条** multichips——互相 `[[链接]]` 引用（同义词/上下位关系），保存时在正文末尾生成「参见：[[X]]、[[Y]]」。
3. 主次分明：基本信息 core；正文常驻；外观/标签 附加设置。

## 四、解析方式

- 无需新解析器；`[[链接]]` 悬浮预览已有（FeatRichText 体系）。
- 可选：`extractRefs(sourceText)` 统计正文引用了哪些词条，反向建议「关联词条」候选。

## 五、实现清单

- [ ] （可选）关联词条 multichips + 参见生成
- [ ] （可选）反向引用统计
