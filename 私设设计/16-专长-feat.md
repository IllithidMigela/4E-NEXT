# 专长（feat）私设编辑器设计

> 优先级：**P1**（预设价值高）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/feat.json`（官方 3202 条，2026-09-07 统计）

## 一、卡片结构（右侧预览）

FeatCard：头部（层级·类型·出处）+ 前提 / 增益 / 特殊 三个固定标签块 + 关联威能表（增益内嵌 `<table>`）。

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| tierZh 层级 | select | ✅（英雄/典范/天命/史诗） |
| featType 类型 | select | ✅ |
| prerequisite 前提 | longtext | ✅（附加设置） |
| benefit 增益 | longtext | ✅（**core**） |
| special 特殊 | longtext | ✅（附加设置） |

## 三、设计要点

1. **专长预设**（核心新增，统计驱动）——基于 3202 条官方专长前提句式与增益开头统计：

| 预设名 | 结构模板 | 依据 |
| --- | --- | --- |
| 检定加值型 | 增益：`你在「技能」检定上获得+N`（技能/数值填空） | 威吓20/运动16/宗教15 高频 |
| 引导神力型 | 增益：`你获得引导神力威能「威能」` | 开头 51 例 |
| 回气增强型 | 增益：`当你使用你的回气时…` | 开头 42 例 |
| 遭遇限制型 | 增益：`每遭遇一次…` | 开头 25 例 |
| 重伤触发型 | 增益：`当你重伤时 / 在遭遇中你第一次重伤…` | 14/17 例 |
| 威能授予型 | 增益：`你可以将一个N级或更低的「类别」威能作为…` | 13/17 例 |
| 流派 · 关联威能表 | 增益末尾自动生成 `<table>`（等级×关联威能） | 流派专长固定结构 |

2. **前提句式提示**（统计驱动）：前提候选择序——职业式（`职业：X`）1955 / 等级式（`N级`）989 / 受训式（`技能受训`）88；输入时提示句式。
3. **关联威能等级表**（可选结构化）：benefit 内嵌 `<table><tr><th>等级</th><th>关联威能</th>` —— 提供「等级×威能」表格编辑器（增删行），保存拼装表格 HTML（对齐官方格式），角色页已有该表解析。
4. 主次分明：基本信息 + 增益 core；前提/特殊/外观/标签 附加设置。

## 四、解析方式

- `parseFeatTable(benefit)`：`<table>` 等级表 → 行数组回填表格编辑器；`serializeFeatTable(rows)` 反拼装。
- 前提/增益为纯文本 + [[链接]]（FeatRichText 已支持悬浮）。
