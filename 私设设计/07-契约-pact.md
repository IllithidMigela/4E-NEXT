# 契约（pact）私设编辑器设计

> 优先级：**P2**（威能引用类）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/pact.json`（官方 8 条：精类/星辰/阴暗/元素/混沌守护 等）
> 依赖：阶段 1「通用威能引用编辑器」组件

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/出处）+ 正文。契约条目正文 = 等级化小节：

```
1级：XX契约之赐 Fey Pact Boon             ← 特性（核心：契约福利）
1级：XX契约武器 Fey Pact Weapon           ← 特性（武器链接）
7级：XX契约武器惩戒 … Retribution
9级：召唤邪术师盟友（XX契约）              ← 威能
11级：魔剑士行动（XX契约） / 契约面貌/诅咒
12级：XX契约祈祷 Invocation               ← 威能
16级：进阶XX契约之赐
20级：XX契约变形
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| sourceText 正文 | longtext | ✅（等级小节） |

## 三、设计要点

1. **等级小节列表**（复用威能引用编辑器）：每小节 = 等级前缀 + 标题 + 引用；特性类带 [[威能]]/[[物品]] 链接，威能类带 `{{威能名}}`。
2. **契约之赐 / 契约武器 专用块**（官方每个契约必含）：两个固定小节——「契约之赐」（触发效果描述）+「契约武器」（武器威能引用），提供固定模板直接生成。
3. 主次分明：基本信息 core；等级小节 core；外观/标签 附加设置。

## 四、解析方式

- 正文章节树 → 小节数组（同 magic-school）；契约之赐/契约武器按 `1级：…契约之赐/契约武器` 标题识别为专用块。
- 保存：小节 → wikitext 拼装。
