# 传奇天命（epic-destiny）私设编辑器设计

> 优先级：**P1**（威能引用类）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/epic-destiny.json`（官方 115 条）
> 依赖：阶段 1「通用威能引用编辑器」；与典范之道共用模板

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/层级·前提）+ 正文。天命条目正文骨架（实测词频）：

```
! {{!!title}}                       ← 标题模板（渲染为条目名）
（引言 + 前提条件：{{!!prerequisite}}）
!! 不朽 Immortality                  ×37   ← 21级天命不死特性
!! 实践天命 Living the Destiny       ×6    ← 30级总结
!! 21级：神圣火花 …                  ← 等级特性（21/24/26/30级）
!! 30级：神圣奇迹 …
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| tierZh 层级 | select | ✅ |
| prerequisite 前提 | longtext | ✅（天命条件面板） |
| sourceText 正文 | longtext | ✅（等级特性） |

## 三、设计要点

1. **等级特性小节**（核心）：21级 / 24级 / 26级 / 30级 特性列表（每节 = 等级 + 标题 + 正文 + 可选威能引用），复用威能引用编辑器；提供「21/24/26/30」四槽位模板。
2. **固定小节**：不朽 Immortality（天命核心特性）+ 实践天命 Living the Destiny——两个固定槽位，提供官方模板。
3. **前提格式化**：正文首段 `前提条件：{{!!prerequisite}}` 由 prerequisite 字段自动生成（已有字段，保存时拼装）。
4. 主次分明：基本信息 core；天命条件 core；等级特性 core；外观/标签 附加设置。

## 四、解析方式

- `sectionTitles` 提取 `N级：…` 小节 + 不朽/实践天命 固定节 → 结构化数组。
- `{{!!prerequisite}}` 模板 → prerequisite 字段回填；保存反向生成。
- 威能小节（如 30级：XX天命威能）提取引用。
