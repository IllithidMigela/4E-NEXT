# 魔法学派（magic-school）私设编辑器设计

> 优先级：**P2**（威能引用类）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/magic-school.json`（官方 6 条：幻术/惑控/防护/塑能/变化/预言）
> 依赖：阶段 1「通用威能引用编辑器」组件（见主文档路线图）

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/出处）+ 正文。学派条目正文 = 等级化小节（特性 + 威能），固定骨架：

```
1级：XX学徒 Illusion Apprentice      ← 特性（获学派威能）
5级：XX专家 Illusion Expert
10级：XX大师 Illusion Master
11级：XX行动 Illusion Action          ← 特性
11级：XX遭遇威能 Illusion Encounter Power   ← 威能
12级：XX辅助威能 Illusion Utility Power     ← 威能
20级：XX每日威能 Illusion Daily Power       ← 威能
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| sourceText 正文 | longtext | ✅（等级小节） |

## 三、设计要点

1. **等级小节列表**（核心新增）：复用「威能引用编辑器」——每小节 = 等级前缀（1/5/10/11/12/20）+ 标题 + 威能引用，保存时拼装回 `!! N级：XX…` 结构。
2. 小节类型标注：特性（学徒/专家/大师/行动）vs 威能（遭遇/辅助/每日）——提供类型徽标，威能小节带 `{{威能名}}` 引用输入。
3. 主次分明：基本信息 core；等级小节列表 core；外观/标签 附加设置。

## 四、解析方式

- 正文章节树：`sectionTitles`（`!! N级：…` 正则）→ 小节数组；威能小节内 `{{[[引用]]}}`/`[[链接]]` 提取威能引用。
- 保存：小节数组 → `!!`/`!!!` wikitext 拼装。
