# 领域（domain）私设编辑器设计

> 优先级：**P1**（威能引用类）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/domain.json`（官方 9 条：大地/风暴/太阳 等）
> 依赖：阶段 1「通用威能引用编辑器」+ 主题模板

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/出处）+ 正文。领域条目正文骨架（实测词频）：

```
领域随意威能 Domain At-Will Power        ×18   ← 三类威能分节，每类含多级条目
领域遭遇威能 Domain Encounter Power      ×9
领域辅助威能 Domain Utility Power        ×9
1级：XX领域特性和威能                    ← 特性（含引导神力）
3级/5级/7级/10级/13级/16级：XX领域特性/遭遇威能   ← 等级特性
11级：虔诚行动 / 至高祝福                 ← 典范动作
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| sourceText 正文 | longtext | ✅（三级威能分节 + 等级特性） |

## 三、设计要点

1. **三类威能分节**（核心）：领域随意 / 领域遭遇 / 领域辅助——三个威能引用列表（分节 + 等级标注），复用威能引用编辑器；官方每类含多级（如 3级/7级/13级 遭遇威能）。
2. **等级特性小节**：1级特性（含引导神力标注）/ 3级…16级 特性 + 11级虔诚行动——小节列表 + 类型标注。
3. **领域种类标注**：引导神力 / 遭遇威能 / 特性（角色页 `warpriestDomains` 已有该解析维度）。
4. 主次分明：基本信息 core；三类威能 + 等级特性 core；外观/标签 附加设置。

## 四、解析方式

- 正文章节树：识别「领域随意/遭遇/辅助威能」三类分节标题 → 三个威能引用列表；`N级：…` 标题 → 等级特性小节。
- 保存：威能列表 + 特性小节 → wikitext 拼装（`!! 领域XX威能` + `!! N级：…`）。
