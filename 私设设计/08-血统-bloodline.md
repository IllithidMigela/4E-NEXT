# 血统（bloodline）私设编辑器设计

> 优先级：**P2**（威能引用类）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/bloodline.json`（官方 2 条：欺诈者/追猎者，典范级血统）
> 依赖：阶段 1「通用威能引用编辑器」组件

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/出处）+ 正文。血统条目 = 典范级等级化小节：

```
11级：XX血统特性 Beguiler Bloodline Feature        ← 特性
12级：XX血统辅助威能 … Utility Power              ← 威能
16级：XX血统特性                                    ← 特性
20级：XX血统每日威能 … Daily Power                ← 威能
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| sourceText 正文 | longtext | ✅（等级小节） |

## 三、设计要点

1. **等级小节列表**（复用威能引用编辑器）：11级/12级/16级/20级 固定四个槽位，特性/威能交替——提供四槽位模板一键生成。
2. 小节类型标注：特性（描述文本）vs 威能（引用），与 magic-school/pact 一致。
3. 主次分明：基本信息 core；等级小节 core；外观/标签 附加设置。

## 四、解析方式

- 同 magic-school：`sectionTitles` 提取 `N级：…` 小节 → 特性/威能分类；威能小节提取引用。
- 保存：小节数组 → wikitext。

## 五、实现清单

- [ ] 通用威能引用编辑器（阶段 1）
- [ ] 四槽位模板（11/12/16/20 级）

## 六、开放问题

1. 血统仅 2 条官方数据，模板槽位是否锁死 4 个？——建议允许自由增删小节，四槽位仅作一键模板。
