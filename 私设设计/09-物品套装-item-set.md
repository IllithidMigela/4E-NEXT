# 物品套装（item-set）私设编辑器设计

> 优先级：**P2**（结构化编辑）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/item-set.json`（官方 38 条）

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/层级）+ 正文。套装条目正文骨架：

```
!! 知识 Lore            ← 背景 lore（含 DC 检定段落），可折叠
!! 套装组成              ← [[物品]] 链接列表
!! 套装增益（2件套/3件套/4件套…）
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| tier 层级 | select | ✅ |
| sourceText 正文 | longtext | ✅（知识/组成/增益 三节） |

## 三、设计要点

1. **套装增益块编辑器**（核心新增）：「2件套 / 3件套 / 4件套 / …」固定块列表——label = 件数，content = 增益文本（可含 [[威能]] 链接）。复用 PowerBlockEditor 的「固定标签」模式，或独立「件数增益」组件。
2. **套装组成编辑器**：[[物品]] 链接 multichips（候选 = 装备库），保存生成「套装组成」节。
3. **知识 Lore 折叠**：复用 `splitThemeSections` fold 机制（背景 lore 折叠 / 机制展开）。
4. 主次分明：基本信息 core；套装组成 + 套装增益 core；外观/标签 附加设置。

## 四、解析方式

- 正文章节树（!!）切出 知识/套装组成/套装增益 三节。
- 套装组成节：`[[链接]]` 提取 → 物品多选回填。
- 套装增益节：`2件套/3件套` 等标题切块 → 件数块数组；保存反拼装。
- 知识节：原样保留下方 textarea。

## 五、实现清单

- [x] 件数增益块编辑器（label=件数 + 文本）
- [x] 套装组成 [[物品]] 链接 multichips（候选装备库）
- [x] 三节拆分解析（知识/组成/增益）+ 反拼装

## 六、开放问题

1. 增益块的「件数」候选范围？（官方常见 2/3/4/5 件套）——建议自由输入数字 + 常用候选。
2. 套装增益是否也支持「威能」形式（部分套装 4 件套给威能）？——若含威能引用，块内文本走 [[链接]] 悬浮即可，不单独做结构。
