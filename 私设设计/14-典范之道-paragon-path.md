# 典范之道（paragon-path）私设编辑器设计

> 优先级：**P1**（威能引用类）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/paragon-path.json`（官方 577 条）
> 依赖：阶段 1「通用威能引用编辑器」+ 传奇天命共用组件

## 一、卡片结构（右侧预览）

GenericCard 纯文本卡片：头部（名称/等级·前提）+ 正文。典范之道正文骨架（实测）：

```
! {{!!title}}                        ← 标题模板
//「引言」//
前提条件：{{!!prerequisite}}
（背景 lore 段落）
!! 11级：XX特性                      ← 起始特性（授予 2 个典范攻击威能）
!! 11级：XX（第二特性）
!! 12级：XX辅助威能 / 典范威能        ← 威能
!! 16级：XX特性
!! 20级：XX每日威能 / 典范威能        ← 威能
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| level 等级 | select | ✅（典范条件面板） |
| prerequisite 前提 | longtext | ✅ |
| sourceText 正文 | longtext | ✅（等级特性） |

## 三、设计要点

1. **等级特性小节**（核心）：11级（起始，2 个）+ 12级 + 16级 + 20级，特性/威能交替——与天命共用 `LevelFeatureSections` 组件；提供四槽位模板。
2. **起始特性威能标注**：11级起始特性授予的 2 个典范攻击威能——小节类型标注 + 威能引用，角色页解析（`paragonPathPowers` 类）对齐。
3. **前提格式化**：正文 `前提条件：{{!!prerequisite}}` 由字段自动生成。
4. 主次分明：基本信息 core；典范条件 core；等级特性 core；外观/标签 附加设置。

## 四、解析方式

- `sectionTitles` 提取 `N级：…` 小节；11级起始特性识别（前两个小节或标题含起始特性）。
- 威能小节提取引用；`{{!!prerequisite}}` ↔ prerequisite 字段双向。
