# 主题（theme）私设编辑器设计

> 优先级：**P1**（威能引用类，复用度最高的模板）· 状态：**设计完成，待实现**
> 数据依据：`dist/data/categories/theme.json`（官方 27 条）
> 依赖：阶段 1「通用威能引用编辑器」；角色页 `splitThemeSections` / `themeStarting` / `themeExtraPowers` / `themeOptionalPowers` 解析已成熟，编辑端对齐

## 一、卡片结构（右侧预览）

主题面板（角色页 `ThemeChapters` 已实现）：主题简介 + 章节树（lore 折叠 / 机制展开）+ 三个威能列表。

官方主题正文骨架（实测词频）：

```
（主题简介引言段，无标题）
!! 起始特性                             ×27   ← 机制（含起始威能授予）
!! 额外特性                             ×27
!! 5级特性 / 10级特性                    ×27
!! 可选威能                             ×26
!! 2级辅助威能 / 6级辅助威能 / 10级辅助威能 ×24~26
（扮演/创建 等 lore 章节）               ← 折叠
```

## 二、数据模型

| 字段 | 类型 | 现状 |
| --- | --- | --- |
| name / nameEn / source | 基本信息 | ✅ |
| sourceText 正文 | longtext | ✅（章节树） |

## 三、设计要点

1. **章节树实时预览**（核心）：编辑正文时右侧卡片用 `splitThemeSections` 实时渲染章节结构——lore 章节（扮演/创建）折叠，机制章节（起始特性起）展开。所见即所得。
2. **三段式威能引用编辑**：起始特性 / 额外特性 / 可选威能 三个分组，每节 = 等级标题 + 威能引用列表（复用威能引用编辑器）；保存时生成 `!! 起始特性` 等标题 + `{{威能名}}` 语法。
3. **等级特性小节**：5级特性 / 10级特性 / 2/6/10级辅助威能——小节列表 + 类型标注（特性/辅助威能）。
4. 主次分明：基本信息 core；三段威能 + 等级特性 core；外观/标签 附加设置。

## 四、解析方式

- `splitThemeSections`（已有）：!!/!!! 章节树 + fold 标记 → 编辑端预览。
- `extractPowerRefs(section)`：`{{[[威能]]}}`/`[[链接]]` → 引用数组；保存反拼装。
- 机制章节范围判定（起始特性之前为 lore）：`theme.ts` 逻辑复用。
